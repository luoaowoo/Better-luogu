# Better-luogu（更好的洛谷）

一个面向算法竞赛训练的 Chrome / Edge Manifest V3 浏览器扩展。

它会在洛谷上提供提交错因诊断、满分复盘、同类练习、被动算法提示、本周训练总结、首页筛选随机题，以及犇犇/文章内容的 AI 文字优化。插件默认保持安静，AI 功能都需要手动点击，不会自动分析、提交、发布或覆盖你的内容。

<a id="features"></a>
## ✨ 功能总览

### 🧾 提交记录侧栏

打开洛谷提交记录页时，页面右侧会出现插件面板：

- `AI 诊断`：非满分提交使用，结合题面、代码、评测信息和题解摘要分析真实错因。
- `复盘分析`：满分提交使用，总结当前解法、题解中的主流/更优思路、复杂度和替代算法。
- `同类练习`：不调用 AI，直接用洛谷题库接口推荐同评级、同标签或来源相近的题目。

诊断和复盘会流式显示模型输出，并展示 token 消耗。插件会尽量过滤“本次没发生却硬说 TLE/RE/MLE”这类跑偏结论。

### 📚 个人错因库

- 点击 `加入错因库` 后，本地保存题号、题名、提交 ID、评测结果、AI 结论和主要错因。
- 同一个提交或同一类错因不会重复保存。
- 数据保存在 `chrome.storage.local`，不做云同步。

### 📊 本周总结

点击浏览器右上角扩展图标，切换到 `本周总结` 页：

- 汇总最近 7 天的提交数、题目数、AC 数、错误数。
- 展示难度分布、中文算法标签分布、错误类型、本周题目和最近错因。
- 根据本周高频标签和难度给出题目推荐；推荐来自洛谷题库接口，不由 AI 编造。
- 生成后缓存 5 分钟，关闭弹窗再打开会直接显示上次结果；超过 5 分钟后再重新生成。
- 不在评测记录页也会尝试根据当前登录用户读取洛谷评测记录。

### 💡 被动算法提示

在题目页的原生操作按钮旁会出现 `算法提示`：

- 必须读题满 5 分钟后才能点击。
- 算法方向来自洛谷题解摘录，AI 只负责提炼关键观察、复杂度和实现注意点。
- 不输出完整代码；题解证据不足时会明确说明，不靠模型猜算法。
- 已加载的提示可收回/打开；只有点 `重新加载` 才会再次调用模型。

### 🎲 首页筛选随机题

在洛谷首页“问题跳转”卡片中新增 `筛选随机题`：

- 可多选难度，命中任一已选难度。
- 可多选算法标签，默认从已选算法中随机挑一个再随机跳题。
- 可勾选 `多个算法必须同时包含`，要求题目同时包含所有已选标签。
- 可选择排除本地记录中已 AC 的题目。
- 算法标签按大致从易到难排序，支持全选/取消全选和搜索。

这个功能完全不调用 AI。

### ✍️ AI 文字优化

在洛谷首页犇犇输入框、新建/编辑文章页面提供 `AI 优化(改为学术风格)`：

- 优化错别字、病句、冗余表达、标点、Markdown 和数学公式格式。
- 可以把杂乱要点整理为 `1. 2. 3.` 编号列表。
- 保留题号、算法名、代码、Markdown、链接和 `@用户名`。
- 优化结果先预览，删除内容显示删除线，新增内容和标点显示下划线。
- 只有点击对勾确认后才会写回编辑器。

<a id="install"></a>
## 🧩 安装

### 从 Release 安装

1. 下载 Release 中的 `Better-luogu-v0.2.1.zip`。
2. 解压到一个固定目录。
3. 打开扩展管理页：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
4. 打开“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择解压后的目录。

### 从源码安装

```powershell
git clone https://github.com/luoaowoo/Better-luogu.git
cd Better-luogu
```

然后在浏览器扩展管理页选择“加载已解压的扩展程序”，选中仓库根目录。

本扩展无构建步骤，不需要 `npm install`，也不需要打包工具。

<a id="config"></a>
## ⚙️ 配置 AI

点击浏览器右上角扩展图标，默认进入 `设置` 页。

需要填写：

- `API Base URL`
  - OpenAI 官方接口可填 `https://api.openai.com/v1`
  - 其他 OpenAI-compatible 接口按服务商文档填写
- `API Key`
  - 你的模型服务密钥
  - 只保存在浏览器本地
- `Model`
  - 例如 `gpt-4o-mini`、`gpt-4.1-mini`，或其他兼容接口支持的模型名

不需要 AI 的功能，例如 `同类练习`、`筛选随机题`，无需配置 API Key。

<a id="usage"></a>
## 🚀 使用方法

### 🧾 诊断提交

1. 登录洛谷。
2. 打开提交记录页，例如：

```text
https://www.luogu.com.cn/record/123456789
```

3. 在右侧面板点击：
   - `AI 诊断`：非满分提交。
   - `复盘分析`：满分提交。
   - `同类练习`：找同评级练习题。

### 📊 生成本周总结

1. 点击浏览器右上角扩展图标。
2. 切换到 `本周总结`。
3. 点击 `生成本周总结`。

如果 5 分钟内已经生成过，重新打开弹窗会直接显示上次结果。

### 💡 获取算法提示

1. 打开洛谷题目页。
2. 正常读题，等待按钮倒计时结束。
3. 点击 `算法提示`。
4. 查看算法方向、关键观察、复杂度和实现提醒。

### ✍️ 优化文字

1. 在犇犇输入框或文章编辑器中写内容。
2. 点击 `AI 优化(改为学术风格)`。
3. 查看预览。
4. 点击对勾确认写回，或点击叉号取消。

<a id="policy"></a>
## 🧠 诊断策略

插件的提示词会把 AI 限制在算法竞赛语境中：

- 先读题面和数据范围，再看提交代码，再结合题解和评测结果。
- 重点关注题意误读、输入输出、建模、复杂度、边界、下标、初始化、溢出、状态转移、图建模、贪心正确性等问题。
- 每个结论都要求有证据。
- 证据不足时必须说明无法确定。
- 禁止编造题意、隐藏数据、题解或最优算法。
- 不做普通软件工程 code review，除非代码问题直接导致竞赛错误。

<a id="privacy"></a>
## 🔒 隐私说明

- API Key 保存在浏览器本地 `chrome.storage.local`。
- 错因库和周报缓存也保存在浏览器本地。
- 使用 AI 诊断/复盘时，会把当前提交相关材料发送给你配置的模型服务。
- 使用算法提示时，会把当前题面摘要和题解摘录发送给你配置的模型服务。
- 使用文字优化时，会把待优化文本发送给你配置的模型服务。
- 使用本周总结时，会把最近 7 天训练统计发送给你配置的模型服务。
- 同类练习和筛选随机题不调用 AI，只请求洛谷题库接口。
- 本项目不提供云同步，不收集遥测数据。

<a id="dev"></a>
## 🛠️ 开发与调试

修改源码后：

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 找到本扩展。
3. 点击“重新加载”。
4. 刷新洛谷页面。

基础自检：

```powershell
node --check background.js
node --check content.js
node --check options.js
node test-selfcheck.js
git diff --check
```

重新打包：

```powershell
New-Item -ItemType Directory -Force -Path dist | Out-Null
Compress-Archive -Path manifest.json,background.js,content.js,options.html,options.js,styles.css,README.md -DestinationPath dist\Better-luogu-v0.2.1.zip -Force
```

```text

├── test-selfcheck.js   # 轻量自检脚本
└── README.md
```

<a id="limits"></a>
## ⚠️ 已知限制

- 仅支持 Chrome / Edge Manifest V3。
- 洛谷页面结构和非公开接口字段可能变化；字段变化时，部分数据会降级或显示为空。
- AI 输出质量取决于题面、题解摘要、提交代码和模型本身。
- 算法提示依赖可读取的洛谷题解；没有题解时不会猜算法。
- 文字优化适合整理表达，确认前仍需自行检查技术内容、公式和代码。
- 同类练习和题目推荐依赖洛谷题库接口结果，不保证覆盖所有合适题目。
